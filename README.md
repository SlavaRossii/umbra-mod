# Umbra — Изнанка

**Хоррор-мод для Minecraft 26.3 · NeoForge 26.3.0.76**

Ночью твоя тень уходит от тебя. Дома появляются вещи-подделки, за спиной слышны шаги, в пещерах ползёт живая тьма.
Всё это просачивается из **Изнанки** — пепельной пещеры без неба под нашим миром. Свет — единственное, что работает,
и его всегда мало.

## Установка
1. Поставь **NeoForge 26.3.0.76** для Minecraft **26.3**.
2. Скачай jar: вкладка **Actions** → последняя зелёная сборка нужной ветки → **Artifacts** → `umbra-mod-jar`.
   - `main` → `umbra-X.jar` — одиночная игра;
   - `server` → `umbra-X-server.jar` — сервер и игра вдвоём и больше (этот же файл ставит каждый игрок).
3. Положи jar в `.minecraft/mods` и начни **новый мир**.

## Что внутри

**Страх в обычном мире.** Тень, шаги за спиной, мимики-подделки, живая тьма, квантовые лабиринты, ночные события
(кровавая луна, туман, тишина), рассудок с галлюцинациями и кошмарами.

**Изнанка.** Восемь биомов, теневые деревни с торговцами и подменышами, затонувший храм, пепельные бури, большой маяк
со смотрителем Яном, Квантовая цитадель и затопленные Глубины.

**Существа.** Ползун, Слепец, Пожиратель света, Подражатель, Тени, Глубинник, статуи, Хранители цитадели,
Плакальщица, Звонарь, пепельные фигуры.

**Боссы.** Смотрящий, Королева подмен, Пастух тьмы, Двойник, Архитектор, Первородная Тень, Утопленный Хранитель,
Павший смотритель. У каждого своё слабое место и своя музыка. Минибоссов призывают ритуалом на **жертвеннике** в Изнанке.

**Снаряжение.** Три набора брони по три ступени, 13 чар Умбры, алтарь эха, мрачная наковальня, артефакты, трофеи;
меч, коса, копьё, кинжал, ножи, лук, посох эха; фонари, оберег, Рассеиватель.

**Сюжет до конца.** Дневник пишется сам, открывает рецепты, ведёт бестиарий, задания и атлас. Путь ведёт через цитадель
к Архитектору и Первородной Тени — и к одной из двух концовок.

## Для разработчиков
- Устройство кода — [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
- Сборка — только в GitHub Actions. Каждая сборка проходит компиляцию, проверку ресурсов (`tools/audit.py`),
  самотест на выделенном сервере (~440 проверок, на ветке `server` ещё и игра вдвоём) и запуск настоящего клиента
  со скриншотами моделей, предметов в руке и построек.
- Модели, текстуры, звуки, музыка и часть данных генерируются скриптами в `tools/` (запуск из корня репозитория).
