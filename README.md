# Umbra (Изнанка)

Хоррор-мод для Minecraft **26.3** на **NeoForge 26.3.0.76**.
Твоя тень уходит от тебя по ночам, дома появляются вещи-подделки, в пещерах ползёт живая тьма, а под миром лежит
Изнанка — пепельная пещера без неба, откуда всё это просачивается. Свет — единственное, что работает.

## С чего начать
- **[Путеводитель для новичка](docs/GUIDE.md)** — что есть в моде, чего бояться и куда идти, шаг за шагом.
- **[Прохождение по шагам + что проверять на баги](docs/WALKTHROUGH.md)** — как призывать боссов, чем их бить, куда идти дальше.
- **[Что делает каждый предмет](docs/ITEMS.md)** — короткий справочник.
- **[Все рецепты](docs/RECIPES.md)** — сетки крафта и какая запись дневника их открывает.
- **[История изменений](CHANGELOG.md)** — что нового в каждой версии.
- **[Игра на сервере](docs/SERVER.md)** — установка и поведение мода, когда игроков несколько.

## Скачать
Готовый jar — во вкладке **Actions**: последняя зелёная сборка нужной ветки → **Artifacts** → `umbra-mod-jar`.
- ветка `main` → `umbra-X.jar` — одиночная игра;
- ветка `server` → `umbra-X-server.jar` — выделенный сервер и игра вдвоём и больше; этот же файл ставит каждый игрок.

Положи jar в `.minecraft/mods`. Лучше начинать в новом мире.

## Что внутри, коротко
- **Страх в обычном мире**: Тень, шаги за спиной, мимики-подделки, живая тьма, квантовые лабиринты, ночные события,
  рассудок и галлюцинации, кошмары.
- **Изнанка**: восемь биомов, сумрачная сталь и эхо-кварц, деревни теней, затонувший храм, пепельные бури.
- **Существа**: Ползун, Слепец, Пожиратель света, Подражатель, Тени, Глубинник, статуи и Хранители цитадели,
  Плакальщица, Звонарь, пепельные фигуры.
- **Боссы**: Смотрящий, Королева подмен, Пастух тьмы, Двойник, Архитектор, Первородная Тень, Утопленный Хранитель —
  у каждого своё слабое место.
- **Маяк и Ян**: лампа, натиски тьмы, поручения смотрителя, полка трофеев.
- **Снаряжение**: три набора брони по три ступени с бонусами комплекта, 13 чар, алтарь эха со свечами, сумрачная
  наковальня, артефакты, улучшение оружия трофеями, копьё, коса, кинжал, лук, ножи, посох эха.
- **Сюжет до конца**: квантовая цитадель → Архитектор → Первородная Тень → две концовки → Новая игра+ и Глубины.
- **Дневник** пишется сам, открывает рецепты, ведёт бестиарий, задания и атлас найденных мест.

## Для разработчиков
- Устройство кода: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md). Планы: [docs/ROADMAP.md](docs/ROADMAP.md).
- Сборка — только в GitHub Actions: компиляция, ревизор ресурсов (`tools/audit.py`), самотест на выделенном
  сервере (~380 проверок, на ветке `server` ещё и два игрока), запуск настоящего клиента с проверкой всех моделей.
- Модели, текстуры, звуки и часть данных генерируются скриптами в `tools/` (запуск из корня репозитория).
