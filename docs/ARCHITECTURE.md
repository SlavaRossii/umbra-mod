# Umbra — how the code is organised

Minecraft 26.3, NeoForge 26.3.0.76, Java 25. Mojang names (the game is no longer obfuscated).

## Packages (`src/main/java/dev/umbra`)

| Package | What lives there |
|---|---|
| `Umbra` | Entry point. Registers everything and routes game events to the managers below. |
| `UmbraConfig` | `config/umbra.toml`: feature switches and difficulty knobs. |
| `registry` | All `DeferredRegister`s: blocks, items, entities, attachments, world-gen feature types, creative tab. |
| `shadow` | The shadow entity and `ShadowManager` (trail recording, spawning, chasing). |
| `steps` | Footsteps behind you. |
| `mimic` | Mimic blocks and the logic that plants them in your base. |
| `darkness` | Living darkness block and seeding. |
| `quantum` | Quantum blocks, the maze builder, the maze core/controller and the change patterns. |
| `sanity` | Sanity meter, hallucinations, hallucination entity. |
| `light` | Everything light-based: Dispeller, eternal torch, `LightSensitive`, `DarknessProof`. |
| `item` | Plain items with behaviour (pills, mirror). |
| `client` | Client-only: renderers, HUD. Never reference it from common code. |
| `command` | `/umbra …` debug commands. |
| `SmokeTest` | CI self-test, runs only with `-Dumbra.smoketest=true`. |

Resources: `assets/umbra` (models, textures, lang en_us + ru_ru), `data/umbra` (recipes, loot, world gen),
`data/minecraft/tags` (mining tags). Textures are generated by `tools/gen_textures.py`.

## Extension points

- **New maze pattern**: implement `quantum.MazePattern`, add it to `MazePatterns.ALL`, add `maze.umbra.pattern.<id>`
  to both lang files. It automatically appears in `/umbra mazepattern` and in the random rotation.
- **New creature that fears light**: implement `light.LightSensitive`; the Dispeller (and future light weapons)
  will call `onLit`. Use `client.SilhouetteRenderer` for quick humanoid visuals.
- **Something that scares the player**: call `Sanity.add(player, Sanity.Shock.X)`; add the constant to
  `Sanity.Shock` so all balance numbers stay in one place. `Sanity.dread(player)` (1.0–3.0) makes things
  more frequent as sanity drops.
- **Light source the darkness must not eat**: implement `light.DarknessProof`.
- **Feature switch**: add a `BooleanValue` to `UmbraConfig` and check it with `UmbraConfig.on(...)`.
- **New item/block**: register in `registry`, add it to `ModTabs`, add model + `items/<name>.json`, lang lines,
  recipe/loot JSON, and a texture function in `tools/gen_textures.py`.

## Build & test

Every push runs `.github/workflows/build.yml`:
1. compile and package the jar;
2. start a real dedicated server with the mod and run `SmokeTest` (world gen, mazes, patterns, mimics,
   shadow, darkness, Dispeller, sanity, pills, ore generation);
3. publish the output to the `ci-output` / `ci-smoke` branches.

What the self-test cannot check: rendering, sounds, and anything that needs a real player's eyes
(hunt pattern, footsteps, hallucination behaviour). Those need a manual pass in game.
