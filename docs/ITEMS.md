# Umbra: что делает каждый предмет

Коротко, по группам. Сетки крафта — в [RECIPES.md](RECIPES.md), путь по игре — в [WALKTHROUGH.md](WALKTHROUGH.md).
**ПКМ** — правая кнопка, **Shift+ПКМ** — с зажатым Shift.

## Основное
| Предмет | Что делает |
|---|---|
| Дневник | Пишется сам: записи о находках, бестиарий, задания, атлас. Каждая запись открывает рецепты. Выдаётся в начале. |
| Страница Хранителей | Читается по порядку (ПКМ), каждая открывает свои рецепты света. Лежит в сундуках шахт, данжей, деревень. |
| Записка исследователя | Сюжет про Марту и Яна. Последняя (8-я) даёт карту Марты. Лагеря исследователей в Изнанке. |
| Успокоительное | +30 рассудка. |
| Антипсихотик | +100 рассудка, но замедление и голод на время. |
| Настойка тишины | 5 минут рассудок не падает; «Ясность» снимает тьму и тошноту. Делается на столе шёпотов. |

## Ресурсы
| Предмет | Что это |
|---|---|
| Кристалл люминита | Главный материал против тьмы. Руда ниже Y≈32 (1–2 кристалла с блока), друзы в кристальных гротах. |
| Люминитовая друза | Блок из люминита; разбирается обратно на кристаллы. |
| Осколок тени | Падает с рассеянной Тени. Для сумрачного камня, разлома, печати пастуха. |
| Сумрачный камень | Рамка разлома в Изнанку (открывается осколком тени). |
| Необработанный сумрак → слиток сумрачной стали | Руда Изнанки; сталь для инструментов, брони, печатей. |
| Блок сумрачной стали | 9 слитков. Для Ключа Изнанки, наковальни, ступени III брони. |
| Эхо-кварц | Кварц Изнанки (с 2.7 его заметно больше): печати, алтарь, улучшения брони, посох эха. |
| Осколок печати | 3–4 с каждого минибосса, 2–3 с Утопленного Хранителя. Нужен для брони ступени III. |
| Пепельный камень, пепельная почва, мёртвое бревно, мглистый гриб, друзы | Блоки Изнанки для стройки и декора (гриб слабо светится). |

## Свет и защита
| Предмет | Что делает |
|---|---|
| Рассеиватель | Вспышка конусом: жжёт живую тьму, рассеивает Тень и галлюцинации, выдаёт мимиков, оглушает тварей. 40 зарядов. |
| Рассвет | Усиленный Рассеиватель (256 зарядов). Падает с Первородной Тени. |
| Люминитовый фонарь | Свет в руке ~20 минут. ПКМ вкл/выкл, Shift+ПКМ с кристаллом — заряд. С 2.8 — объёмный, держится на вытянутой руке (и фонарь Марты, и «Рассвет»). |
| Фонарь Марты | Свет в руке, который не гаснет; пока в руке — рассудок понемногу растёт. Чертёж от Яна. |
| Вечный факел | Факел, который живая тьма не гасит. |
| Люминитовая лампа / светильник | Блоки света. Светильник пожиратели света не едят — строй им в Изнанке. |
| Оберег | Блок: кормишь кристаллами (1 ≈ день). В радиусе нет спавна монстров, Тени, шагов, мимиков, кошмаров. |
| Зеркальце | Показывает мимиков; против Смотрящего — держи и смотри ему в глаз. |
| Светящаяся стрела | При попадании — маленькая вспышка как у Рассеивателя. |
| Квантовый компас | Указывает ближайший квантовый лабиринт и его режим. |

## Безумие (стол шёпотов, работает при низком рассудке)
| Предмет | Что делает |
|---|---|
| Стол шёпотов | Ритуалы при низком рассудке: настойка тишины, маска, клинок. |
| Маска безумца | Видно невидимое и мимиков, проходишь фантомные стены; рассудок уходит. |
| Очки ночного зрения | На голову вместо шлема: в темноте видно, как днём. Заряд на час (тратится только в темноте), чинятся кристаллом люминита на наковальне. Крафт: LIL / S S (L — кристалл люминита, I — сумрачный слиток, S — кожа). |
| Клинок отчаяния | Меч: чем ниже рассудок, тем сильнее (до +10 урона); когда рассудок ниже 60, его удары кровоточат тёмным и слышно сердце. |

## Боссы и сюжет
| Предмет | Что делает |
|---|---|
| Печать взгляда / подмены / пастуха / отражения | Кладётся на Жертвенник в Изнанке: подношения в чашу, место вокруг, ПКМ пустой рукой — ритуал, и выходит Смотрящий / Королева подмен / Пастух / Двойник. В творческом режиме ПКМ зовёт сразу. |
| Жертвенник | Блок для печатей. Просыпается только в Изнанке; что нужно каждой печати — подскажет сам и запишет дневник. Shift+ПКМ пустой рукой — забрать всё назад. |
| Глаз Смотрящего, Корона подмен, Посох пастуха, Зеркальная маска | Добыча с минибоссов; все четыре + блок сумрачной стали = Ключ Изнанки. Посох ещё идёт на косу. |
| Ключ Изнанки | ПКМ в Изнанке — направление и расстояние до цитадели; ключом по запечатанной двери — будит Архитектора. |
| Сердце бездны | ПКМ в Изнанке — призыв Первородной Тени. Падает с Архитектора. |
| Сердце Первородной Тени | Выбор концовки: в лампу маяка на полной силе — «Рассвет», в темноте — «Тьма». |
| Трофеи боссов (6 шт.) | На полку у Яна (все шесть — награда) или вплавить в оружие на наковальне. |
| Карта Марты | ПКМ в Изнанке — путь к маяку. С первого минибосса или из последней записки. |
| Рог смотрителя | Коснись лампы маяка — запомнит его; зовёт на натиск и переносит к башне. |
| Лампа маяка | Кормишь люминитом (4 на уровень, 4 уровня): шире круг, куда тьма не заходит. |
| Ключ Глубин | Стоя в воде Изнанки, ПКМ — спуск в Глубины (один вдох на 90 с); внутри ПКМ — обратно. Крафт: осколок печати + 4 чешуи Глубинника + 4 эхо-кварца. |
| Чешуя Глубинника | Падает с Глубинника (чёрные озёра Изнанки), 1–2. Нужна для Ключа Глубин. |
| Ключ Хранителя | Падает с Утопленного Хранителя. Открывает сундук Хранителя в святилище Глубин (тратится). |
| Пластинки (8) | Треки боссов для проигрывателя — слушать без боя. Каждый босс роняет свою; ещё лежат в сундуках структур (чаще всего в Глубинах и в призовом сундуке лабиринта). |
| Пластинки (8) | Треки боссов для проигрывателя. Каждый босс роняет свою. |
| Посох Хранителя | Подарок Яна после «Рассвета». ПКМ — луч света маяка (24 блока, сквозь всех тварей в линии); Shift+ПКМ — круг-оберег 10 блоков на минуту. Заряжается у горящей лампы маяка. Светит в руке. |

## Подарки Яна (чертежи за его поручения)
| Предмет | Что делает |
|---|---|
| Фонарь Марты | см. выше. |
| Подзорная труба Яна | Твари, на которых смотришь в трубу, светятся сквозь стены ~10 секунд. |
| Колокольчик Хранителя | ПКМ: твари в 12 блоках отлетают, замедлены и ослаблены, теряют цель. Перезарядка 30 с. |

## Артефакты (на нагрудник, через наковальню)
| Предмет | Эффект |
|---|---|
| Пепельная застёжка | Тихие шаги, нет урона от падения, буря не слепит. |
| Печать Архитектора | Видно сквозь фантомные стены и проходишь скрытую стену цитадели; лабиринт не перестраивается. |
| Жемчужина Хранителей | Дыхание под водой, рассудок тратится медленнее. Из сундука Хранителя в Глубинах. |

## Мастерская
| Предмет | Что делает |
|---|---|
| Алтарь эха | Чары Умбры за эхо-кварц и опыт. ПКМ пустой рукой — свечи и цена; ПКМ вещью — зачаровать. |
| Свечи: люминитовая, толстая (×2), оплывшая, канделябр (×3) | Вокруг алтаря (до 4 блоков) повышают уровень эха: 4 / 12 / 24 / 64. До 4 свечей на блок. |
| Вентиль, колокол, лампа Хранителей | Устройства Глубин: вентиль поднимает решётку, 4 колокола будят Утопленного Хранителя, лампа зажигается кристаллом. |
| Сундук Хранителя | Морской сундук на помосте святилища. Не ломается; открывается только Ключом Хранителя; после каждой победы над Хранителем снова полон и заперт. |
| Мрачная наковальня | Окно со слотами: починка снаряжения Умбры, артефакт на нагрудник, трофей в оружие. |
| Полка трофеев | Шесть мест для трофеев боссов; полная — награда. |

## Оружие
| Предмет | Что делает |
|---|---|
| Сумрачные меч, топор, кирка, лопата | Инструменты сумрачной стали (между алмазом и незеритом). Меч: три полных удара подряд — третий режет широкой дугой всех впереди (50%). Топор: полный замах на миг оглушает (замедление), земля трескается. |
| Люминитовое копьё | Боевое копьё в два блока длиной: бьёт на 2 блока дальше, +3 урона тварям Изнанки. Колет (видно и со стороны). Удар на бегу — выпад: пробивает первого и бьёт стоящего за ним (70%). |
| Коса Пастуха | Медленная; полный замах режет всех в 3 блоках вокруг цели (60%) и оставляет дугу из душ. Убийство косой — +полсердца. |
| Теневой кинжал | Быстрый, колет; удар в спину ×2. Убийство со спины — короткий рывок скорости. |
| Люминитовый лук | Лук; стрелы бьют тварей Изнанки ×1,5 и подсвечивают их. Полностью натянутая стрела на 4 с оставляет свет там, куда попала. |
| Теневой нож | Метательный (ПКМ): со свистом летит остриём вперёд, 5 урона, в спину ×2; промахнувшись, втыкается в стену; половина подбирается. |
| Посох эха | ПКМ: звуковой удар на 16 блоков сквозь броню и всех в линии. 1 эхо-кварц, перезарядка 3 с. |
| Люминитовая эгида | Щит: блокирует как обычный, в руке смягчает удары тварей вдвое и поджигает бьющего. Поднятая в последний момент (за ~0,5 с до удара) — отражает удар: бьющий получает половину и слепнет. |

## Броня
| Набор | Каждая деталь | Полный комплект | Вся ступень III |
|---|---|---|---|
| Сумрачная — бастион | бережёт рассудок | Сопротивление в Изнанке, удары тварей −15% | «Бастион»: на краю гибели Сопротивление II + 4 сердца (раз в 90 с) |
| Теневая — призрак | тише шаги | быстрее бег, ночное зрение в темноте; присел — дальние твари теряют тебя | «Ускользание»: каждый 5-й удар твари мимо |
| Люминитовая — свет | жжёт теней рядом, рассудок в темноте | удары тварей −20%, пожиратели света горят, нет эффекта тьмы | «Ореол»: светишься сам, твари рядом слабеют |

Ступень II — кузнечный стол: эхо-кварц + деталь + материал набора (слиток сумрака / блок люминита / осколок тени).
Ступень III — эхо-кварц + деталь + осколок печати. Любая ступень III сильнее незеритовой.

## Чары (алтарь эха, книги в сундуках Умбры)
Эхо, Жатва, Вкус тьмы, Сияние, Ясность, Теневой разрез, Резонанс — оружие; Вспышка — лук; Тишина — ботинки;
Якорь — поножи; Чутьё — шлем; Пустота — броня; Проклятие шёпота — проклятие (не бери).

## Служебное (в творческом)
Яйца призыва всех существ, квантовая стена и стена лабиринта (нерушимые блоки построек).
